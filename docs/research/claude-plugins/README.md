# Anthropic's plugin documentation, saved for reference

These seven pages are Anthropic's Claude Code plugin documentation, saved as Markdown on 2026-10-21
(each page's first lines point to the docs index). They are kept as fetched, so mod-builder, which
is itself a plugin, can be checked against them. [`../Mods`](../Mods/README.md) holds the mod
documentation, which the mods mod-builder builds follow.

The live pages change between Claude Code releases. When a page here, the live page and the
behaviour of your build disagree, trust your build first, then the live page.
