# Anthropic's Claude Code documentation on CLAUDE.md, saved for reference

These two pages are Anthropic's Claude Code documentation on writing `CLAUDE.md` and the files it
loads (`.claude/rules/`, imports, nested `CLAUDE.md` files), saved as Markdown on 2026-10-23 (each
page's first lines point to the docs index). They are kept as fetched, so this repository's
`CLAUDE.md` and `.claude/rules/` can be checked against them. [`../Mods`](../Mods/README.md) and
[`../claude-plugins`](../claude-plugins/README.md) hold the mod and plugin documentation.

The live pages change between Claude Code releases. When a page here, the live page and the
behaviour of your build disagree, trust your build first, then the live page.
